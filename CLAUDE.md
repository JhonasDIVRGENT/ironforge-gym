# CLAUDE.md

Este proyecto utiliza AGENTS.md como documento principal de arquitectura,
convenciones y reglas de desarrollo.

Antes de crear, modificar o eliminar código:

1. Leer AGENTS.md completo.
2. Respetar su arquitectura.
3. No crear paquetes, frameworks o clases adicionales sin autorización.
4. Mantener compatibilidad con Java 21 y Maven.
5. Ejecutar `mvn clean compile` después de cambios relevantes.

Si una instrucción de una tarea entra en conflicto con AGENTS.md,
detenerse y señalar el conflicto antes de modificar la arquitectura.
